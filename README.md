# NIDS-ML

A machine-learning network intrusion detection system built with Python and Flask, using the NSL-KDD dataset.

**Live Demo:** [https://nids-ml-production.up.railway.app/]

---

## Project structure

```text
app/          Flask application, templates, and static assets
data/         Local NSL-KDD dataset files (not committed)
model/        Trained model artifacts (model.pkl, scaler.pkl, encoder.pkl)
notebooks/    Exploratory analysis and experiments
tests/        Automated tests
