About the project

Network Intrusion Detection System

NIDS-ML applies supervised machine learning to network connection records and flags potential intrusions.

Dataset and prediction

The application is trained on the NSL-KDD training set and evaluated on its held-out test set. It classifies each connection as normal or intrusion.

Protocol, service, and connection-state features are one-hot encoded. Numeric connection features are standardized. The saved Random Forest model returns a class and its estimated probability.

Architecture

  1. Presentation: responsive Bootstrap 5 pages rendered with Flask and Jinja.
  2. Application: Flask routes validate form data, run predictions, and render evaluation results.
  3. Machine learning: scikit-learn estimator, categorical encoder, and numeric scaler loaded from model/ at startup.
  4. Evaluation: test-split accuracy, F1-score, and confusion matrix visualized with Chart.js.

This model is a decision-support tool; predictions should not be treated as a substitute for security monitoring and analyst review.
